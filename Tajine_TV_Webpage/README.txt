TAJINE TV WEBPAGE

1. Rename your poster image to:
   poster.png

2. Put poster.png in the same folder as index.html.

3. Upload both files to a GitHub repository.

4. Enable GitHub Pages:
   Settings -> Pages -> Deploy from branch -> main -> /root -> Save

5. GitHub will give you a public link.
   Open that link in the LG TV browser in Italy.

To change the poster later:
- Replace poster.png with the new image.
- Keep the exact filename: poster.png
- Commit the change to GitHub.
- Refresh the TV browser.

The page is designed for a TV display:
- black background
- full-screen image
- original aspect ratio preserved
- no buttons or extra interface
